1. Project DNA (Permanent): Python-based Windows terminal Gemini CLI with an interactive prompt/TUI, local tools, encrypted API-account storage, and persistent preferences. Its primary goal is practical terminal chat and coding assistance with resilient Gemini access.

2. Latest Implementation:
- Terminal input/paste: all platforms use prompt_toolkit `PromptSession` when available (auto-installed on first run via `ensure_dependencies`). A single `InMemoryHistory` and a single `PromptSession` are created once before the REPL loop via `build_repl_prompt_session`, pre-seeded from `prompt_history.txt`, and reused on every call so Up/Down arrow history works and the terminal stays stable across turns. `append_prompt_history` writes back to `prompt_history.txt` after each submit. Windows wraps `Win32Input` (created once inside `build_repl_prompt_session`) to combine multiline console paste. The prompt message uses `FormattedText` (not `ANSI()`) so prompt_toolkit knows the exact visual width of the prefix, and `refresh_interval=0` + `wrap_lines=False` prevent mid-input layout jitter. POSIX/Termux fallback chain when prompt_toolkit is absent: (1) `_readline_prompt` — Python's built-in `readline`, gives arrow history + Tab slash completion; (2) `read_posix_prompt` — raw reader with fixed ESC/CSI sequence drain so arrow keys no longer print garbage. ESC closes the completion menu using prompt_toolkit's default behavior. `/device` reports the detected environment. See `Recentfixes.md`.
- Response output wrapping: `render_markdown_text` now word-wraps plain paragraphs, bullet points, and numbered list items to `term_width` (from `os.get_terminal_size()`) before printing, so long lines never break mid-word at the terminal's hard column boundary. Code blocks, tables, and headings are not wrapped (they handle their own layout).
- PC remote access uses SSH through `run_shell_command`, including requests that mention port 7777. The connection command is `ssh -i ~/.ssh/id_ed25519_windows_pc -o WarnWeakCrypto=no-pq-kex -p 22 nahid@192.168.0.101`; SSH defaults to the PC user's home folder. Never ask for or store the SSH password. LAN Flask integration is removed from the CLI.
- `/add_device` opens an interactive SSH device manager; each saved entry has exactly a name and full SSH connection command. Entries can be viewed, added, modified, or removed. Commands are stored in `model_prefs.json`; passwords and remote commands are not stored in the connection field.
- `gemini_cli.py`: Added loopback proxy using encrypted `api_accounts.lock`, quota/rate-limit failover, JSON/SSE forwarding, explicit stream close, safe account/model-prefixed diagnostics, and `/test` synchronization into Pi's failover catalog.
- `README.md`: Documents proxy, model synchronization, and safe logging.
- `C:\Users\nahid\.pi\agent\auth.json`, `models.json`, `settings.json`: Configured failover-only Pi provider, enabled models, and default `google-failover/gemini-3.1-flash-lite`. On Windows with Scoop Git, `settings.json` must also set `shellPath` to `~\\scoop\\apps\\git\\current\\bin\\bash.exe`; without it Pi may fail to run commands because it cannot discover Scoop's Git Bash.
