# Newspaper Top 10 News

## Description
Fetches and displays the top 10 news headlines from a reliable source (e.g., NewsAPI).

## Goal
Fetch and display top news headlines filtered by category.

## Instructions
1. **Prerequisites:** Requires a NewsAPI key (https://newsapi.org/) or public news feed.
2. **Implementation:** Create or run a Python script using `requests` to call a news API.
3. **Usage:** `python get_top_news.py --category <category>` (e.g., business, technology).
