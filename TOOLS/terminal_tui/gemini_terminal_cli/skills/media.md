# Movie and TV Show Status Tracker

## Goal
When the user provides a movie or TV show name, search the web to find the latest updates on upcoming seasons, new movie sequels, prequels, spin-offs, or expected release dates.

## Instructions
1. **Identify the Subject:** Extract the movie or TV show title provided by the user.
2. **Perform Web Search:** Search for the title combined with terms like "season release date", "renewal status", "in production", "upcoming sequel", or "news".
3. **Analyze Findings:** Look for official announcements, credible industry news (e.g., Variety, Hollywood Reporter, Deadline), or reliable production updates.
4. **Report Results:** Present the findings clearly with:
   - **Current Status:** (e.g., Renewed, Cancelled, In Production, Released)
   - **Expected Release Date / Window:** (If available)
   - **Key Details:** (Brief summary of what is being made, casting news, or plot hints)
   - **Source/Recency:** (When the news was last updated)
