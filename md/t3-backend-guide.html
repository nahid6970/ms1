T3 Code Headless Backend Guide

Complete installation, launch, and management manual for Stable and Nightly servers.

Prerequisites

Ensure you have the following ready before deploying the headless orchestration layer:

  • Node.js: LTS version (v18+ recommended).
  • AI Agent CLIs: Pre-authenticate any tools you intend to use (e.g., claude auth login for Claude Code or your respective Codex environment credentials).

Stream Selection

Stable Channel

Standard Release

Best for production use cases, stable orchestration engines, and regular development environments.

Nightly Channel

Prerelease Edge

Includes Orchestrator V2 updates, experimental multi-agent workflows, and fast-paced daily updates.

1. Installation Methods

NPM Global Install

Install the package directly via the Node Package Manager:

# Stable Track
npm install -g t3

# Nightly Track
npm install -g t3@nightly

Native Script Binaries

Install as a standalone native binary engine with configured path mapping:

macOS / Linux:

# Stable
curl -fsSL https://t3.codes/install.sh | sh

# Nightly
T3CODE_CHANNEL=nightly curl -fsSL https://t3.codes/install.sh | sh

Windows (PowerShell):

# Stable
irm https://t3.codes/install.ps1 | iex

# Nightly
$env:T3CODE_CHANNEL="nightly"; irm https://t3.codes/install.ps1 | iex

2. Launch & Serve Options

Instant On-Demand Execution

Run the backend environment instantly without global installation hooks:

# Stable
npx t3 serve

# Nightly
npx t3@nightly serve

Project Folder Context

To initialize the headless backend server directly targetted at a specific repository:

cd /path/to/your/codebase
t3 .

Native Background Service

For installations handled via the Native Script Binaries, manage the background daemon natively:

# Install background agent daemon
t3 service install

# Control states
t3 service start
t3 service stop
t3 service update

Advanced Background Management (PM2 alternative)

For custom global installations, manage execution with PM2:

npm install -g pm2
pm2 start t3 --name "t3-backend" -- serve

# Monitor state
pm2 status
pm2 logs t3-backend

3. Safe Uninstallation & Stream Switching

Important: Always clear the package runner engine cache when shifting between Stable and Nightly environments to avoid runtime artifact conflicts.

Step 1: Stop Services

t3 service uninstall
# or if using PM2: pm2 delete t3-backend

Step 2: Clean Binary Directories

NPM Methods:

npm uninstall -g t3

Native Script Directories (Manual Purge):

# macOS & Linux
rm -rf ~/.t3

# Windows (PowerShell)
Remove-Item -Recurse -Force "$HOME\.t3"

Step 3: Flush Application Caches

npx clear-npx-cache
